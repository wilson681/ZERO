# ZERO RIPS · 线上评级卡抽卡平台 MVP

对标 [90s Card](https://90scard.com/)、[DOPA](https://dopa-global.com/)、GameStop Power Packs 这类
"线上撕卡包 / rip pack" 平台的可运行原型：用户花固定金额开一个数字卡包，
有几率抽中 PSA 10 / PSA 9 评级重卡（大奖）或普通卡，抽中后可以选择**回收换币**继续抽，
或**申请实物发货**。

## 快速开始

零依赖，只需要 Node.js 18+：

```bash
node server.js
# 打开 http://localhost:3000
```

## 已实现的功能

- **三个卡包**：复古经典包（◉200/次，头奖初版喷火龙 PSA 10）、现代大奖包（◉200/次，头奖月亮伊布 Alt Art PSA 10）、全鉴定至尊包（◉1000/次，每抽必得评级卡砖）
- **概率公示**：每个卡包完整展示奖池、单卡概率、期望回报（EV）和 RTP
- **开包动画**：卡包摇晃 → 撕开 → 翻牌，大奖有全屏特效；支持单抽和十连
- **卡库管理**：按 90% 标价一键回收换币、单卡回收、申请发货（演示）
- **可验证公平（Provably Fair）**：
  `roll = HMAC_SHA256(serverSeed, clientSeed:nonce)` 前 8 位十六进制 ÷ 2³²。
  开包前公示 `sha256(serverSeed)`，玩家可自定义 clientSeed，轮换种子后公开旧种子明文，
  每一抽都可以逐条复验（页面内置验证工具）
- **中奖走马灯**、开奖历史（含每一抽的 nonce/roll 凭证）
- 状态持久化到 `.data/state.json`（演示用；生产环境换数据库）

## 概率设计

概率以百万分之一为最小单位，服务端启动时强制校验每个卡包权重总和恰好为 100%。
奖品按「价值 ÷ 包价」分为六档：普通 < 0.4x ≤ 优良 < 1x ≤ 稀有 < 3x ≤ 史诗 < 10x ≤ 传说 < 50x ≤ 圣杯。
当前三个包的 RTP（返还率）约在 81%–91%，与真实平台的量级一致（可在 `data.js` 调整）。

## 这是演示，不是成品

上线一个真实平台还需要（按优先级）：

1. **账号系统与数据库**（当前是单用户内存态 + JSON 文件）
2. **真实支付**（Stripe / 本地支付渠道）与充提风控
3. **实物库存对账**：每张奖池卡必须对应仓库里一张真实的评级卡，抽走即锁定下架
4. **物流发货流程**（地址、运费、保价）
5. **合规**：这类"付费抽随机实物"在多数司法辖区被视为博彩或准博彩——需要法律意见、
   年龄验证（18+）、强制概率公示、自我限制工具；日本、马来西亚、美国各州要求都不同
6. IP 合规：销售正版实体卡适用首次销售原则，但网站素材、卡图授权需要单独评估

## 目录结构

```
server.js   # 零依赖 HTTP 服务：API + 静态文件 + 抽卡引擎 + provably fair
data.js     # 卡包 / 卡池 / 概率定义（权重制，启动时校验）
public/     # 前端：index.html + style.css + app.js（无框架）
.data/      # 运行时状态（已 gitignore）
```
